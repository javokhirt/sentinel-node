# docs

Notes I keep while building sentinel-node. Three kinds:

- **`decisions/`** — choices I made and why, especially the ones where I picked
  one option over another that also would have worked. Written at the time, not
  reconstructed later.
- **`bug-hunts/`** — bugs that took real effort to find, and how I found them.
  What the symptom was, what I thought first, what it actually was.
- **`log.md`** — running journal. Short entries, mostly for me.

Numbering is just chronological (`0001`, `0002`, ...). I don't renumber or
rewrite old entries when I change my mind later — I add a new one and link back.
The wrong turns are the useful part.
